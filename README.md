# Vrishavahana - Custom Tailoring Fashion Website

![Vrishavahana Banner](images/image1.jpeg)

## 🌟 Overview

Vrishavahana is a premium custom tailoring and fashion design platform that brings traditional craftsmanship into the digital age. The website allows users to explore curated fashion designs, customize every detail, and get outfits tailored precisely to their measurements.

## ✨ Features

### 🎠 Interactive Hero Carousel
- 3D-style rotating carousel showcasing different fashion categories
- Auto-rotating with manual navigation controls
- Blurred background effect that changes with each slide

### 👗 Design Gallery
- Categorized collections: Women, Men, Kids, Bridal
- Product cards with pricing, ratings, and customization options
- Responsive grid layout

### 🎨 Customization Studio
- Color selection with interactive swatches
- Fabric options (Cotton, Silk, Linen, Velvet, Chiffon)
- Size selection (XS to XL)
- Sleeve and neck style customization
- Live price updates based on selections

### 📏 Measurement System
- Unit toggle (cm/inches)
- Comprehensive measurement form (Chest, Waist, Hip, Sleeve, Length, Shoulder)
- Fit preferences (Regular, Slim, Loose)

### 💰 Pricing Plans
- **Basic Stitch** - LKR 2,500 (Casual wear)
- **Signature Craft** - LKR 6,500 (Most Popular)
- **Bridal Couture** - LKR 18,000 (Premium service)

### 👥 Expert Consultation
- Live chat support
- Video call scheduling
- Sketch upload capability

### 📞 Contact & Booking
- Contact information form
- Service selection chips
- Date and time picker
- Success notification system

## 🛠️ Technologies Used

- **HTML5** - Structure and content
- **CSS3** - Styling, animations, responsive design
- **JavaScript** - Interactive carousel, price calculator, form handling
- **Google Fonts** - Cormorant Garamond & Jost fonts
